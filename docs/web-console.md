# Web 控制台

零依赖的单页控制台，随服务一起启动，打开 `http://127.0.0.1:8000/`。

## 合成

- 文本输入、采样参数（temperature / top_p / top_k / 格式）。
- 可选已保存音色（下拉选择），或上传参考音频 + 参考文本做零样本克隆。
- 结果播放与下载，可一键把结果回填为参考音频。

## 批量合成

- 上传 `.txt` 或粘贴文本，按句拆分逐句合成。
- 可选已保存音色，或上传参考音频 + 参考文本，对每句做零样本音色克隆。
- 实时进度与句子清单，完成后下载 ZIP（含 `manifest.json`）。

## 模型管理

- 统计卡片 + 列表行，支持按源安装 / 继续安装 / 删除，下载进度。

## 音色库

- 合成页「存为音色」：填写参考音频与参考文本 → 命名 → 保存，之后两个页面都可从下拉直接选用。
- 「删除音色」：确认后删除索引与参考音频文件。

## 快捷键

`Ctrl/Cmd + Enter` 合成。
